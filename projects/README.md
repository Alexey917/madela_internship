# Board Games Shop

Интернет-магазин настольных игр с микросервисной архитектурой,
SAGA-оркестрацией и платёжным шлюзом.

## Сервисы

- **Catalog** — управление каталогом товаров
- Inventory — резервирование остатков (скоро)
- Orders — оркестрация SAGA (скоро)
- Payments — платёжный шлюз (скоро)
- Notifications — уведомления (скоро)
